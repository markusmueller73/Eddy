# Eddy
A lightweight text editor for the terminal.

Eddy should run on Linux, MacOS and Windows and is written in Rust (v1.94). It is licensed under the MIT license.


## Dependencies

* crossterm v0.29.x


## Notes

This project is made by me to learn more about Rust.
The original project was described here: https://viewsourcecode.org/snaptoken/kilo/index.html and a nice Rust version of this tutorial is here https://philippflenker.com/hecto/

Suggestions are welcome.
